Reminders and offline use

For a reminder, add a date and time when editing a task. While Orbit is open, it can show due reminders. iPhone notifications when the app is fully closed require a separate push system.

After publishing to GitHub Pages, open the site in Safari → Share → Add to Home Screen. Launch once with internet to cache the files. Task storage remains specific to that installation/browser.
